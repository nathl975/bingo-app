# Bingo app

## Overview
The Bingo App is a web-based application designed to provide an interactive and engaging bingo game experience. Built using Vue.js and powered by Vite, this app allows to play bingo in real life with friends or family.

## Features
- Interactive bingo board with real-time updates.
- Responsive design for seamless use on desktop and mobile devices.
- Built with modern web technologies (Vue.js, Vite).
